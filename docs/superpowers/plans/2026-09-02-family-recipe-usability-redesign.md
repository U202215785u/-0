# 家宴可用性重做实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把当前只能跑通流程的家宴 PWA 重做为手机端真正可用的中文家庭菜谱工具。

**Architecture:** 保留本地优先 PWA、固定字段 canonical JSON、IndexedDB 本地状态和点菜码交接。先补齐有公开来源、可在家庭厨房执行的菜谱数据，再重做手机首页、详情、周计划、采购、点菜和烹饪闭环；桌面端保留更高密度布局。

**Tech Stack:** React 19、TypeScript、Vite、Dexie、Zod、Vitest、Testing Library、Playwright、vite-plugin-pwa。

## Global Constraints

- 至少 50 道完整可烹饪菜谱，且每道菜保留公开来源作者或机构和来源链接。
- 用户可见的菜名、材料、数量、步骤、标签、时间和难度全部使用中文；不得出现英文执行内容。
- 不凭空补写来源没有提供的数量、步骤、营养、作者或出处；不在 App 内抓网页、调用 AI 或编辑菜谱。
- 手机优先，支持 320、360、390、430 像素宽度；不能横向溢出，主要触控目标不小于 44px。
- 妻子只能点菜和生成点菜码；不能收藏、改周计划、开始烹饪或修改菜谱。
- 不增加账号、后端、云同步或复杂安全系统。
