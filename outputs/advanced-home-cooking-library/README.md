# 高级家常菜资料库

这是一个中餐为主、家庭厨房可执行的来源型菜谱库。它不是对任何创作者内容的镜像：每个条目都保留原始公开来源，配方信息仅在原始来源已公开时才结构化记录。

首批已核验 54 道：炒 9、蒸 7、汤 7、煎炸 6、主食 6、凉菜 5、烧 4、煲炖 3、基础汤底 1，以及 6 道用于练习煎封、乳化、烘烤和香料平衡的外来菜。完整目录在 `INDEX.md`。

## 使用方式

1. 在 `INDEX.md` 中按菜类、时间和技法选择菜。
2. 打开每一行的原始来源，确认食材版本与完整上下文。
3. 只有条目目录中实际存在的 `.cook` 文件可直接用于备料、计时和份数缩放；首批提供一份干炒牛河示例。
4. 其余条目是已核验的来源索引，烹饪时请打开对应原始页面；`source-summary` 尤其需要以原始来源为准。
5. 做完后从 `trials/trial-template.md` 复制一份记录。试做结论不覆盖原始做法，而是形成你的个人版本。

## 来源可信度标签

- `verbatim-public`：原始公开页面明确提供可转录的配料、用量和流程。
- `structured-transcription`：原始公开内容被结构化排版，但没有补写未公布的量化信息。
- `source-summary`：来源公开、作者可识别且有技术价值，但公开信息不足以建立完整量化菜谱；烹饪前必须打开原页或原视频。

## 管理方案

库的原始格式是 [Cooklang](https://cooklang.org/)，可用文本编辑器或 Cook Editor 打开；Cooklang 支持份数缩放、计时器和购物清单。要获得网页化管理、菜单和采购清单，可选择导入或手工录入到 [Tandoor Recipes](https://github.com/vabene1111/recipes) 或 [Mealie](https://mealie.io/)。

建议将整个目录放入私有 Git 仓库：保留原始来源、每次试做记录和自己的修订历史。不要将原作者的付费内容、视频下载或未授权全文转载到仓库。

## 目录

- `INDEX.md`：已核验菜品总索引、技术标签和直接来源。
- `INDEX-SCHEMA.md`：为个人试做记录扩展字段的空表模板。
- `SOURCES.md`：来源登记与访问记录。
- `recipes/`：仅存可依据公开原始信息结构化的 Cooklang 菜谱。
- `trials/`：每次试做的客观记录。
- `templates/`：新增菜品与试做模板。

## 家庭复刻流程

先按原始来源做一遍，再记录实际食材品牌、锅具、火力、时间和成品偏差。一个菜连续做三次且结果稳定后，才把个人调整写为新版本，例如 `v1.1-home-wok`。不要把个人改动标为原作者做法。
